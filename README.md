# SAFL-HACM

Official implementation of **SAFL-HACM: Semi-Asynchronous Federated Learning with Heterogeneity-Aware Coordination Mechanism in Mobile Edge Computing Networks**.

SAFL-HACM is designed for federated learning in heterogeneous mobile edge computing environments. This repository currently provides part of the core implementation of the proposed framework.

> **Note:** The complete implementation, experimental configurations, and supporting scripts will be released after the paper is officially published.
